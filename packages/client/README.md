# @stakit/client

Typed TypeScript client for [stakit](../../) routers — HTTP (unary + stream) and
WebSocket (duplex). Generic over the `Router` type your server emits via
`router.generate_ts()`. Never throws on an application error (those ride in the
result and are narrowed with `isOk` / `isError`); only real network failures
reject. See `docs/transport.md` for the wire contract.

## Create a client

```ts
import { createClient, isOk, isError } from '@stakit/client'
import type { Router } from './types' // generated by stakit-router

const client = createClient<Router>({
  url: 'https://api.example.com/app', // base (used for every call)
  headers: { authorization: token }, // base headers
  streamUrl: 'https://api.example.com/stream', // optional (defaults to url)
  wsUrl: 'wss://api.example.com/ws', // optional (defaults to url)
  defineClientActions: {
    // server→client handlers
    showToast: (p) => {
      /* … */ return 'ok'
    },
  },
  onError: (err) => err, // fires only on a transport failure (see below)
  fetch: customFetch, // optional (defaults to global fetch), e.g. expo/fetch
})
```

Transport failures reject (after `onError`): a failed request, a non-2xx
answer — a `TransportError` with `status`, `code` (the `x-error-code` header),
`retryAfter` (seconds) and the start of the `body` — or a stream that breaks off
before its end (`code: 'stream_interrupted'`). Action errors never reject; they
ride in the result (`error.type` is the stable code to branch on).

Calls are `POST` with the params as a JSON body — params never ride in a POST
url. Uploads send them as the multipart `q` field next to the `file` parts.
Pass `{ method: 'GET' }` per call to put them in `?q=` instead (no files).

## Unary — one or many actions in one request

```ts
const r = await client.fetch({
  greet: { name: 'alice' },
  version: null,
})

if (isOk(r.greet)) r.greet.data.message // typed
if (isError(r.greet)) r.greet.error.code // { code, type?, message, fields?, data? }
```

`fetch` takes a map of `action → params` and returns a map of
`action → ActionResult`. `isOk` / `isError` narrow each entry to `.data` /
`.error`.

## Per-call overrides (fan out to any server)

Every field is optional and affects only that call — the client base is never
mutated.

```ts
await client.fetch(
  { greet: { name: 'x' } },
  {
    url: 'https://vm-42.internal/app', // override base url
    headers: { authorization: vmToken }, // merged over base headers
    files: [file], // multipart upload (params go in the `q` form field)
  },
)

// opt into `?q=` for a cacheable read (default is POST + JSON body; no files)
await client.fetch({ version: null }, { method: 'GET' })
```

## Stream

```ts
const controller = new AbortController() // optional: stop it from elsewhere
for await (const frame of client.stream(
  { count: { n: 5 } },
  { signal: controller.signal },
)) {
  if (isOk(frame.count)) console.log(frame.count.data)
}
```

Leaving the loop early (`break`, `return`, a throw) closes the connection.

## WebSocket (duplex + server→client calls)

```ts
const conn = client.connect({
  defineClientActions: {
    showToast: (p) => {
      /* … */ return 'ok'
    },
  },
})
await conn.send({ progress: { n: 3 } })
for await (const frame of conn.stream) {
  // server→client `client_call`s are auto-dispatched to defineClientActions
}
conn.close()
```

## Headers

```ts
client.setHeaders({ authorization: t }) // replace all
client.setHeaders((prev) => ({ ...prev, authorization: t })) // functional update
```
